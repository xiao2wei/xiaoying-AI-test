**问：** 校内申诉从知道权利受侵害之日起多久内提出？因不可抗力逾期，障碍消除后多久可以提起？

**实际回答：**

> 《辽宁科技大学教职工校内申诉处理暂行办法（修订）》第十一条规定，申诉人应在知道或者应当知道其权利受到侵害之日起30个工作日内向申诉处理委员会提出申诉。
> 因不可抗力或其他特殊情况而致逾期的，在障碍消除后10个工作日内可以向申诉处理委员会提起申诉，逾期不再受理。

### 第2轮

**问：** 这里的30天和10天都是工作日吗？请分别说明从什么时候开始计算。

**实际回答：**

> 《辽宁科技大学教职工校内申诉处理暂行办法（修订）》第十一条规定，申诉人应在知道或者应当知道其权利受到侵害之日起30个工作日内向申诉处理委员会提出申诉；该期限按工作日计算，起算点为知道或者应当知道权利受到侵害之日。
> 因不可抗力或其他特殊情况而致逾期的，在障碍消除后10个工作日内可以向申诉处理委员会提起申诉，逾期不再受理；该10日期限按工作日计算，起算点为障碍消除后。

> 第十一条 申诉人应在知道或者应当知道其权利受到侵害之日起30个工作日内向申诉处理委员会提出。

- D24 / D24-C012，辽宁科技大学教职工校内申诉处理暂行办法（修订），第十一条；PDF第184页，印刷第179页；版本日期2021-05-30。
