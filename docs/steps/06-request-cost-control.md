实际发现一个评分两次消耗近2万输出tokens却没有JSON；现改为low推理强度，并重新校准16项（配置改变，不能用此前high分数冒充验证）。输出截断直接明确失败，避免相同参数重复烧token。代码和缓存区分low/high。本轮新规则不要求回答模型与评分器同强度；评分仍为独立Pro模型。
