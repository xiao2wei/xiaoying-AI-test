## 设计

每组包含一个问题、两个独立改写，或两轮真实对话。改写组各问法独立运行，整组均通过才通过；上下文组使用上一轮实际模型输出，不注入标准答案。所有题均来自唯一PDF；检索索引只读取data/processed/chunks.json，evaluation不进入知识库。按事实主题划分，同一事实与改写不能跨开发/正式集合；同一制度的独立条款允许共享，因此不宣称未见制度泛化。

标准证据以必需单元计分，单元内ID可为等价证据，单元间均需覆盖。冲突题需要双方条款；通用附则用于背景审查，但未写优先关系本身不能证明任何替代结论。资料外题检查全部文档目录和相关条款，并保存全库关键词零命中结果；零命中本身不被当作不存在的唯一证明。

故障注入只制造工具不可用，不伪造原文或模型回答。包含一次性搜索/读取失败、持续失败、达到工具上限。持续故障无法读取的题在评测前标为M02不适用；搜索成功但读取失败仍评价初次召回。无证据题的召回记N/A。

## 实际操作与核验

Codex起草52组并逐项对照提取原文，程序验证证据全字段；不是人工复核。版本差异直接使用PDF里的真实条款，没有添加合成政策。暂未让任何问答模型访问正式标签。

运行：

~~~powershell
python scripts/build_dataset.py
python -m unittest discover -s tests -v
~~~

## 限制

这是小规模单PDF测评，不能推断对其他组织或当前生效制度的效果。关键表格按原文符号核对。正式评测后的返修必须保留首次成绩并标明测试已用于改进。
