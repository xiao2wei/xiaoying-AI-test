建议仅对不改变资料、检索、提示词、模型或业务决策的确定性代码修复，采用：

1. 全部原真实记录进行本地回放、哈希与结构校验；记录复用来源，不称为新模型运行。
2. 所有行为会改变的组重新真实运行；包括原先失败以及虽然成功但经过被修复分支的组，不能只挑失败题。稳定性受影响时，该场景预定3次全部重新运行，不挑最好一次。

4. 原失败保留；若改动检索、提示词、回答策略或模型，仍按原约定全量真实重跑。
5. 质量阈值、40组类别、30次稳定性、人工复核要求全部不变。
