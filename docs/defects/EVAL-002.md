# EVAL-002：裁判将未说出的标准要点计作未引用事实

发现记录：examples/step06/agent-dev-v2-scores-v2/DEV02.json。裁判正确判定遗漏“报销应符合预算及范围”，但错误把该未说出的内容放入facts并判为未引用，导致M07被错误扣分。

根因：事实拆分边界未机械校验，裁判混淆遗漏判分与事实引用统计。

修复：facts中的每条原子事实必须带逐字来自实际claims.text或gaps的answer_span；程序验证其确实出现在答案中，并保证实际claim不整条漏评。缺失要点只影响points/正确率，不虚构为已输出事实。格式检查失败将整条评分标为judge_error，不能自动删除不利事实来提高成绩。

四项确定性测试覆盖未说出要点、实际事实、非空答案空事实与纯拒答。继续保留14个校准样本，并用修正评分器完整复评两种方案。原评分完整保留。

补充发现：v3校准中裁判将“请确认口径”标为非事实却仍放入facts；DEV06又出现以“间接请求”为由放过未追问的条件。继续修复为更清晰的单一评分规范、通过要点也必须给答案原句定位，并将独立Pro裁判切换为thinking enabled（内部思维不存储，只保存最终JSON及usage）。问答模型配置未改变。

最终验证：有效开发评分见examples/step06/agent-scores-v6、baseline-scores-v6；评分错误0。程序检查34/34；校准14项与建议标签一致14/14，实际人工确认仍待提供。
