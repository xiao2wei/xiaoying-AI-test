# EVAL-004：评分原句跨相邻claim时被错误拒绝

v5评分中DEV03和DEV07的通过要点使用了相邻两条claim拼成的连续原句，逐字存在于最终answer，但程序只允许在单条claim中匹配。该程序错误将有效评分标为judge_error。

修复：要点评分定位在实际claims.text与gaps依显示顺序连接的完整答案中校验。仍只做空白归一化，不能引用标准答案或跳接不连续原句。原子事实的单句定位规则保持不变。

对v5全部真实评分响应重新执行确定性校验，生成独立v6评分目录；不改变AI判断内容、回复ID或分数建议，不新增模型调用，不覆盖v5。此为程序评分复算，不冒充新一轮模型测试。

最终验证：有效开发评分见examples/step06/agent-scores-v6、baseline-scores-v6；评分错误0。程序检查34/34；校准14项与建议标签一致14/14，实际人工确认仍待提供。
